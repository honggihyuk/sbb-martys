# gracestars.kr 구조 분석 (역공학)

> 2026-11-11, 로그인한 화면 캡처와 외부에서 보이는 HTML을 바탕으로 정리했습니다.
> 원본 소스는 볼 수 없어서, 화면 구성과 동작을 보고 추정한 내용입니다.

## 1. 사이트 개요

| 항목 | 내용 |
|---|---|
| 이름 | 마르투스(Martys) — 2026 청년 신약 성서지리 답사 준비 |
| 형태 | 로그인해야 쓸 수 있는 회원 전용 웹앱. 로그인하지 않으면 모든 주소(robots.txt 포함)가 로그인 화면으로 이동해요 |
| 렌더링 | 브라우저에서 자바스크립트로 그리는 SPA 형태. 서버가 처음 보내는 HTML에는 `<title>`과 메타 태그만 있어요 |
| 모바일 | `viewport-fit=cover`, `mobile-web-app-capable`, `apple-mobile-web-app-title` → 홈 화면에 추가해서 앱처럼 쓰는 PWA 구성 |
| 디자인 | 흰 배경, 파란 포인트 색, 가운데 좁은 본문(약 730px), 둥근 회색 상자, 큰 D-day 숫자 |
| 권한 | 관리자 모드와 이용자 모드가 로그인으로 나뉨. 조장·리더만 볼 수 있는 화면(회의록)이 있음 |

## 2. 공통 레이아웃

```
┌ 헤더 ───────────────────────────────────────────┐
│ "2026"(파랑) 청년 신약 성서지리        [사진] 홍기혁 │ → /me
│ 말씀 묵상  체력 증진 │ 팀 구성  조별 활동  모임 기록  공지사항•  │ 회의록 │
└─────────────────────────────────────────────────┘
  본문 (가운데 정렬)
```
- 메뉴는 세 묶음으로 나뉘고, 사이에 얇은 세로선이 있어요.
- 현재 메뉴는 글자가 진해지고 밑줄이 생겨요.
- 공지사항 옆 파란 점은 새 공지가 있다는 표시예요.

## 3. 화면별 구조

| 주소 | 화면 | 구성 |
|---|---|---|
| `/` | 홈 | 소제목(마르투스 · Martys) → 큰 제목 → **출발까지 D-day**(2027년 2월 1일 월요일 출발) → 최근 공지 4개(회색 상자) → 2칸: **이번 주 말씀**(주차, 경로, 사도행전·서신서 체크, 묵상하기) / **체력 증진**(시작까지 D-day, 이번 주 미니 달력, 운동 달력 보기) → **묵상 여정** 지도(바울의 경로 위에 회원 사진, n/32 읽음) |
| `/study` | 말씀 묵상 | 사도바울의 전도여행 10.5–1.24, 진행 막대(11/32). 탭: **16주 한눈에**(지도 + 1차·2차·3차·로마 호송 여정별 주차 목록, 체크 표시, 기록 초기화) / **주차별로 읽기**(확대 지도, 이전·다음 주 이동, 16칸 진행 막대, 본문 2개 체크) |
| `/fitness` | 체력 증진 | 12.1–1.31, 시작까지 D-day, 12월·1월 달력. 시작일부터 날짜를 눌러 체크 |
| `/team` | 팀 구성 | (캡처 없음) 조 편성 화면으로 추정 |
| `/group` | 조별 활동 | 7개 조, 단체 사진은 조장이 올림. 탭: **조원·사진**(내 조는 크게, 조장 배지, 사진 바꾸기/지우기) / **조별 의견**(`?view=notes`, "이번 성서지리 팀에 바라는 점", 우리 조 의견 수정하기, 다른 조 의견 더 보기, 마지막 수정자·날짜) |
| `/moments` | 모임 기록 | 월별 묶음(2026년 11월 1개), 사진 카드(여러 장이면 1/2 표시), 날짜·제목·내용·전체 보기·작성자, 기록하기 버튼 |
| `/notice` | 공지사항 | 날짜, 제목, 내용, 관리자용 수정/삭제, 댓글 펼치기(댓글 n), 댓글 삭제 |
| `/minutes` | 회의록 | 🔒 조장·리더만 볼 수 있어요, 회의록 쓰기, 빈 화면 안내 |
| `/me` | 내 정보 | 프로필 사진, 이름, 소속·성별(송도 · 남), 사진 바꾸기/지우기, 로그아웃 |

## 4. 데이터 구조 추정

| 모임 기록 | 제목, 내용, 모임 날짜, 사진 여러 장, 작성자 |
| 공지 / 댓글 | 제목, 내용, 작성일 / 공지, 작성자, 내용, 작성일 |

## 5. 이 프로젝트(sbb-27)에서 만든 방식

| gracestars.kr | sbb-27 (Spring Boot + Thymeleaf) |
|---|---|
| SPA 화면 | 컨트롤러 → 서비스 → 리포지토리 → Thymeleaf 템플릿 (기존 question 패키지와 같은 구조) |
| 로그인 필수 | `SecurityConfig`: `/member/**`만 열고 나머지는 `authenticated()` |
| 관리자 / 이용자 | SecurityFilterChain 2개: `/admin/**` → 관리자 로그인(`/admin/login`), 나머지 → 이용자 로그인(`/member/login`) |
| 조장·리더 전용 | `MemberRole.LEADER`, `/minutes/**` → `hasAnyRole("LEADER", "ADMIN")` |
| 체크 기록 | `StudyCheck`, `FitnessCheck` 엔티티 (POST 폼으로 체크/해제) |
| 사진 업로드 | `FileStore` → `uploads/` 폴더에 저장, `WebConfig`로 `/uploads/**` 제공 |
| 헤더의 내 정보, 새 공지 점, 현재 메뉴 | `GlobalModelAdvice`(@ControllerAdvice)로 모든 화면에 `loginMember`, `hasNewNotice`, `currentUri` 전달 |
| 묵상 여정 지도 | 실제 지도 데이터(Natural Earth) 대신 주차별 도착지를 칩으로 보여주고, 회원 사진을 그 위치에 표시 |
| 모임 기록 사진 여러 장 | 한 장만 올리도록 단순화 |
